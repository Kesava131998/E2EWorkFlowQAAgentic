# Manual Test Cases — ARW-5: AR Status Widget – Display Applied Payer Category Filter

Jira: https://vwiki281-1785763863770.atlassian.net/browse/ARW-5

## Acceptance Criteria Mapping
- **AC1** — Display Filter Indicator (AR Status widget shows the filter icon when a Payer Category filter such as HMO is applied; hidden when no filter is applied)
- **AC2** — Display Applied Filter on Hover (hovering the filter indicator shows a tooltip with the applied Payer Category, e.g. "Payer Category Filters (HMO)")
- **AC3** — Update When Filter Changes (indicator and tooltip reflect the currently applied filter when it is changed or removed)
