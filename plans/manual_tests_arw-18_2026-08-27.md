# Manual Test Cases — ARW-18: Task Updates Widget – Display Applied Payer Category Filter

Source: Jira ARW-18 description & acceptance criteria (no Excel/Swagger input for this ticket).

| # | AC | Type | Priority | Scenario | Pre-conditions | Test Data | Steps | Expected Result |
|---|----|------|----------|----------|-----------------|------------|-------|-------------------|
| 1 | AC1 | Happy Path | High | Filter indicator displays on Task Updates widget when a Payer Category filter is applied | User logged in and on the Dashboard page (`/dashboard`) with the Payer Category filter cleared | Payer Category = "Income" | 1. Verify the Dashboard page has finished loading (spinner hidden).<br>2. Verify the Task Updates widget is visible on the Dashboard.<br>3. Verify the Payer Category dropdown control is visible.<br>4. Click the Payer Category dropdown to open it.<br>5. Verify the "Income" option row is visible in the dropdown.<br>6. Click the "Income" checkbox.<br>7. Verify the Apply button is enabled.<br>8. Click Apply.<br>9. Verify the loading spinner is hidden after the filter is applied.<br>10. Verify the Task Updates widget's filter icon is visible. | 1. Dashboard is loaded (spinner not visible).<br>2. Task Updates widget is displayed.<br>3. Payer Category dropdown control is displayed.<br>4. Dropdown panel opens and options are listed.<br>5. "Income" option row is displayed.<br>6. "Income" checkbox becomes checked.<br>7. Apply button is enabled.<br>8. Filter is submitted and dropdown closes.<br>9. Spinner is hidden, widget data has refreshed.<br>10. Filter icon is displayed on the Task Updates widget. |
| 2 | AC1 | Negative | Medium | Filter indicator does not display on Task Updates widget when no Payer Category filter is applied | User logged in and on the Dashboard page with the Payer Category filter reset to its unfiltered state | None (no filter selected) | 1. Verify the Dashboard page has finished loading (spinner hidden).<br>2. Verify the Task Updates widget is visible.<br>3. Verify the Payer Category dropdown shows no applied filter value.<br>4. Verify the Task Updates widget's filter icon locator resolves to zero visible elements. | 1. Dashboard is loaded.<br>2. Task Updates widget is displayed.<br>3. Payer Category dropdown displays its unfiltered/default state.<br>4. No filter icon/indicator is shown on the Task Updates widget. |
| 3 | AC2 | Happy Path | High | Tooltip shows the applied Payer Category filter text on hover | Payer Category filter is applied with a single category, e.g. "Medicaid" | Payer Category = "Medicaid" | 1. Apply the "Medicaid" Payer Category filter as in TC1 (steps 4–9).<br>2. Verify the Task Updates widget's filter icon is visible.<br>3. Scroll the filter icon into view.<br>4. Hover over the Task Updates widget's filter icon.<br>5. Verify the tooltip becomes visible.<br>6. Read the tooltip text. | 1. Filter is applied and widget refreshes.<br>2. Filter icon is visible.<br>3. Filter icon is scrolled into the viewport.<br>4. Hover triggers the tooltip to render.<br>5. Tooltip is visible.<br>6. Tooltip text reads `Payer Category Filters (Medicaid)`. |
| 4 | AC2 | Edge Case | Medium | Tooltip reflects all selected categories when multiple Payer Categories are applied | Payer Category dropdown is open with the filter reset to unfiltered | Two Payer Category options selected (e.g. first two available options) | 1. Open the Payer Category dropdown.<br>2. Select two Payer Category checkboxes.<br>3. Click Apply.<br>4. Verify the loading spinner is hidden.<br>5. Hover over the Task Updates widget's filter icon.<br>6. Verify the tooltip is visible.<br>7. Read the tooltip text. | 1. Dropdown panel opens.<br>2. Both checkboxes become checked.<br>3. Filter is submitted.<br>4. Widget data refreshes.<br>5. Hover triggers tooltip.<br>6. Tooltip is visible.<br>7. Tooltip text contains both selected category names. |
| 5 | AC3 | Happy Path | High | Filter indicator and tooltip update when the Payer Category filter is changed to a different category | Payer Category filter is already applied with one category (e.g. "Medicaid") | Change filter from "Medicaid" to a different available category | 1. Confirm the current tooltip text reflects "Medicaid".<br>2. Open the Payer Category dropdown.<br>3. Uncheck "Medicaid" and select a different available category.<br>4. Click Apply.<br>5. Verify the loading spinner is hidden.<br>6. Hover over the Task Updates widget's filter icon.<br>7. Verify the tooltip is visible.<br>8. Read the tooltip text. | 1. Tooltip initially shows "Medicaid".<br>2. Dropdown opens.<br>3. Previous category is unchecked, new category is checked.<br>4. Filter is submitted.<br>5. Widget data refreshes for the new filter.<br>6. Hover triggers tooltip.<br>7. Tooltip is visible.<br>8. Tooltip text reflects the newly selected category, not "Medicaid". |
| 6 | AC3 | Happy Path | High | Filter indicator disappears and tooltip is cleared when the Payer Category filter is removed | Payer Category filter is applied with at least one category | Remove/clear all selected Payer Category options | 1. Open the Payer Category dropdown.<br>2. Uncheck all currently selected Payer Category checkboxes.<br>3. Click Apply (or close the dropdown if Apply is disabled with nothing selected).<br>4. Verify the loading spinner is hidden.<br>5. Verify the Task Updates widget's filter icon locator resolves to zero visible elements. | 1. Dropdown opens.<br>2. All checkboxes become unchecked.<br>3. Filter is cleared and dropdown closes.<br>4. Widget data refreshes to the unfiltered state.<br>5. No filter icon/indicator remains on the Task Updates widget. |

**Note on RBAC/Permission coverage:** ARW-18's acceptance criteria describe a display-only filter indicator with no role-based access restriction, so no RBAC/Permission case is included for this ticket (consistent with how the same indicator pattern was scoped for the AR Status and Overdue Tasks widgets).
