# Manual Test Cases — SCRUM-44: Bulk Update(Facility + Payer / Resident + Payer Category)

**Module**: task_list
**Jira**: https://vwiki281-1785763863770.atlassian.net/browse/SCRUM-44
**Date**: 2026-08-10

## Acceptance Criteria Reference

| AC | Text |
|----|------|
| AC1 | The filter bar displays a Bulk Mode setting with two options: "Facility + payer" and "Resident + payer category" |
| AC2 | "Facility + payer" is the default selected mode on page load |
| AC3 | In "Facility + payer" mode, the two filter dropdowns show Facility and Payer, matching current behavior |
| AC4 | In "Resident + payer category" mode, the two filter dropdowns show Resident and Payer Category |
| AC5 | Resident dropdown includes the facility |
| AC6 | Switching modes clears any currently selected filter values |
| AC7 | Apply Filters and Clear behavior works identically in both modes |
| AC8 | The task table results reflect the correct filter logic for whichever mode is active |
| AC9 | "Apply Filters" is disabled until both dropdowns in the active mode have a value selected |
