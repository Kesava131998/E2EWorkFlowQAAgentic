# Manual Test Cases — SCRUM-41: Split "Overdue Tasks" into Two Columns

Jira: https://vwiki281-1785763863770.atlassian.net/browse/SCRUM-41

## Acceptance Criteria Mapping
- **AC1** — "Overdue Tasks" column no longer appears on the Biller Activity Report
- **AC2** — "Overdue Overpayment Tasks" column shows correct count of open overpayment tasks with Follow Up Date < today, per biller
- **AC3** — "Overdue Open Balance Tasks" column shows correct count of open balance tasks with Follow Up Date < today, per biller
- **AC4** — A biller with no overdue tasks of a given type shows 0 in that column
- **AC5** — 0 shows in green, all other numbers in red
- **AC6** — Summary/total row sums each column independently and correctly
- **AC7** — Exported report reflects the two new columns with accurate data
- **AC8** — Column order places Overdue Open Tasks before Overdue Overpayment Tasks
