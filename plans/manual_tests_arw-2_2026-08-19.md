# Manual Test Cases — ARW-2: Dashboard – Add Payer Category Filter Functionality

Jira: https://vwiki281-1785763863770.atlassian.net/browse/ARW-2

## Acceptance Criteria Mapping
- **AC1** — Open Payer Category Filter (user can click the Payer Category filter on the Dashboard to open the dropdown)
- **AC2** — Search Payer Category (user can search for "HMO" in the search field and view the matching result)
- **AC3** — Select and Apply Payer Category (select "HMO" and click Apply; Dashboard data filters based on the selected category)
- **AC4** — Display Applied Filter (after applying, "HMO" is displayed as the selected value in the filter)
