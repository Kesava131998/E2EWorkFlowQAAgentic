# Manual Test Cases — SCRUM-38: [FE] Activity Report — Split "Overdue Tasks" into Two Columns

**Module**: activity_report
**Source**: Jira SCRUM-38 description + acceptance criteria
**Date**: 2026-08-10

## Definitions (from ticket)
- **Overdue Task** — an open task whose Follow Up Date is before today's date.
- **Overdue Open Balance Tasks** — count of overdue tasks where Balance > 0.
- **Overdue Overpayment Tasks** — count of overdue tasks where Balance < 0.
