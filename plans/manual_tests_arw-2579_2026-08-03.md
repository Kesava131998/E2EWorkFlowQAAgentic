# Manual Test Cases — ARW-2579: FE - Add a Payment Schedule to a Case

Jira: https://axg.atlassian.net/browse/ARW-2579
Figma: https://www.figma.com/design/hTnMqvwgU7TqM9RHlM63MW/UI-Edit--Case-view---Payment-schedule

## Acceptance Criteria Mapping
- **AC1** — Modal trigger & structure (empty-state CTA / populated-view button, title/subtitle)
- **AC2** — Payer field rules (eligibility filter, existing-schedule disable + tooltip)
- **AC3** — Schedule Type/Details, Payment Method, Auto-Pay fields, Save-button gating
- **AC4** — Save behavior (duplicate prevention, toast, table refresh)
