# Manual Test Cases — ARW-33: Highest Balances Widget – Display Applied Payer Category Filter

**Module:** sup_dashboard
**Source:** Jira ARW-33 description + acceptance criteria (no Excel/Swagger source for this ticket)

## Acceptance Criteria Recap
- **AC1 — Display Filter Indicator:** When the Medicaid Payer Category filter is applied, the Highest Balances widget should display the filter icon/indicator. When no Payer Category filter is applied, the indicator should not display an applied filter.
- **AC2 — Display Applied Filter on Hover:** Hovering the filter indicator on the Highest Balances widget shows a tooltip reading "Payer Category Filters (Medicaid)".
- **AC3 — Update When Filter Changes:** When the Payer Category filter is changed or removed, the Highest Balances widget's filter indicator and tooltip must reflect the current applied filter.
