# Manual Test Cases — SCRUM-47

**Ticket**: SCRUM-47 — Preserve Task List and Aging Filter Selections when Global Facility Filter Changes
**Module**: tasks
**Date**: 2026-08-11

## Acceptance Criteria

- AC1: Changing the global facility filter refreshes available values for Resident, Facility, Payer, and Assigned To filters.
- AC2: Existing selected values remain selected when they still match at least one selected global facility.
- AC3: Existing selected values are removed when they no longer match any selected global facility.
- AC4: Adding facilities to the global filter does not clear existing valid Task List filter selections.
- AC5: Removing facilities from the global filter only removes Task List filter selections that are no longer valid.
- AC6: The Task List reloads using the preserved valid filters after the global facility filter changes.
- AC7: If every selected value in a filter is invalidated by the global facility filter change, the filter is cleared.
