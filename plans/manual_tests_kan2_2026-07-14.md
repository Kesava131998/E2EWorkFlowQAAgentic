# Manual Test Cases — KAN-2: Task 2

**Ticket:** KAN-2
**Summary:** Payment-schedule calendar icon inline in the Task List grid, next to resident name
**Module:** task_list
**Generated:** 2026-07-14

## Acceptance Criteria

- **AC1** — A calendar icon appears inline after the resident name when a payer schedule exists for that resident/payer combination.
- **AC2** — No icon appears when no payer schedule is configured for that resident/payer.
- **AC3** — The icon only renders when the active grouping includes a payer level above the resident; if no payer is present in the grouping hierarchy above the resident, the icon is never shown, regardless of whether a schedule exists.
- **AC4** — The icon is not clickable and has no hover state beyond triggering the tooltip.
- **AC5** — Hovering the icon shows a tooltip with three lines: a muted label "Payment schedule on file", the schedule value, and the payment method.
- **AC6** — The icon does not interfere with the resident name hyperlink.
